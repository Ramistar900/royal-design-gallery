# ROYAL Design V17 source

V17 is assembled from the complete reviewed source set in this repository:

- sources/ROYAL_Android_Icons_v2.zip: 22 matching SVG and Android VectorDrawable XML pairs.
- restaurant_tv_3d_icons.zip: 37 store + 42 TV icon concepts, each with static and native SMIL animated SVG states (158 SVG files).
- restaurant_tv_launcher_ui_icons.zip: 16 launcher UI concepts with static, animated and focused states (48 SVG files).
- restaurant_tv_launcher_icons.zip: four original orange/purple brand and banner assets.
- restaurant_tv_launcher_icons (1).zip: four alternate gold/blue brand and banner assets.
- restaurant_tv_launcher_ui_icons (1).zip: byte-identical backup of the canonical UI archive; verified and not duplicated.

V17 contains 125 gallery entries: 117 functional icon concepts plus eight brand/banner assets. Every entry has an inline motion preview. The 95 source animations remain unchanged; subtle ROYAL SMIL wrappers are generated for 22 Android system icons and eight static brand assets. The launcher UI retains all 16 focused states. Original source SVG/XML files are never overwritten by generated motion copies.
