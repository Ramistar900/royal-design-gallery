# حزمة الأيقونات - نسخة شفافة (v2)

- store/ : تطبيق المتجر (ذهبي)، static و animated
- tv/ : تطبيق التلفاز والقنوات (أزرق)، static و animated
- launcher_ui/ : واجهة اللانشر (فيروزي)، static و focused (عند التركيز) و animated
- player/music/ : أيقونات مشغل الموسيقى (فيروزي)
- player/video/ : أيقونات مشغل الفيديو (أزرق)
- PLAYER_UI_DESCRIPTION.md : وصف الأيقونات وتخطيط الواجهتين

جميع الملفات بخلفية شفافة، والحركات مضبوطة حسب وظيفة كل أيقونة.
