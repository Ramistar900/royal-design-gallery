# واجهة مشغل الموسيقى والفيديو

## أيقونات مشغل الموسيقى (`player/music`)
- **تشغيل** (`play.svg`): بدء التشغيل أو استئنافه. الحركة: نبض ناعم عند الضغط.
- **إيقاف مؤقت** (`pause.svg`): إيقاف التشغيل مؤقتاً. الحركة: تنفس خفيف.
- **التالي** (`next.svg`): الانتقال إلى المقطع أو الفيديو التالي. الحركة: انزلاق قصير نحو اليمين.
- **السابق** (`prev.svg`): الرجوع إلى المقطع أو الفيديو السابق. الحركة: انزلاق قصير نحو اليسار.
- **عشوائي** (`shuffle.svg`): تشغيل القائمة بترتيب عشوائي. الحركة: تحريك جانبي خفيف.
- **تكرار** (`repeat.svg`): تكرار القائمة أو المقطع. الحركة: دوران مستمر منتظم.
- **رفع الصوت** (`volume_up.svg`): زيادة مستوى الصوت. الحركة: تكبير نابض قصير.
- **موسيقى** (`music.svg`): فتح مكتبة الموسيقى. الحركة: طفو ناعم.
- **ألبوم** (`album.svg`): عرض غلاف الألبوم كقرص فينيل. الحركة: دوران بطيء مستمر.
- **مؤثرات الصوت** (`equalizer.svg`): فتح المعادل وضبط الترددات. الحركة: نبض يشبه حركة الموجات.
- **قائمة التشغيل** (`queue.svg`): عرض المقاطع القادمة. الحركة: انزلاق خفيف.
- **إضافة إلى قائمة** (`playlist_add.svg`): إضافة المقطع إلى قائمة تشغيل. الحركة: ارتفاع خفيف عند الإضافة.
- **كلمات الأغنية** (`lyrics.svg`): عرض الكلمات متزامنة مع الصوت. الحركة: ظهور وخفوت ناعم.
- **سماعات** (`headphones.svg`): تحديد مخرج الصوت. الحركة: تنفس خفيف.
- **ميكروفون** (`mic.svg`): وضع الكاريوكي أو تسجيل الصوت. الحركة: نبض خفيف.
- **إعجاب** (`heart.svg`): إضافة المقطع إلى المفضلة. الحركة: نبضة قلب مزدوجة.
- **مشاركة** (`share.svg`): مشاركة المقطع مع الآخرين. الحركة: تكبير خفيف.
- **تحميل** (`download.svg`): حفظ المقطع للاستماع دون اتصال. الحركة: سهم ينزل بنعومة.
- **بحث** (`search.svg`): البحث في المكتبة أو الفيديوهات. الحركة: عدسة تنزلق بلطف.
- **الإعدادات** (`settings.svg`): فتح إعدادات المشغل. الحركة: دوران بطيء جداً.
- **رجوع** (`back.svg`): العودة إلى الشاشة السابقة. الحركة: انزلاق نحو اليسار.

- **فيديو** (`video.svg`): فتح قسم الفيديوهات. الحركة: انزلاق صغير.
- **حفظ** (`bookmark.svg`): حفظ نقطة زمنية في الفيديو. الحركة: نبض خفيف.
- **الإعدادات** (`settings.svg`): فتح إعدادات المشغل. الحركة: دوران بطيء جداً.

## تخطيط شاشة مشغل الموسيقى
- **الأعلى:** رجوع، عنوان القائمة، بحث، إعدادات.
- **المنتصف:** غلاف الألبوم بشكل قرص فينيل يدور أثناء التشغيل، مع اسم الفنان وعنوان الأغنية.
- **أسفل الغلاف:** شريط التقدم والوقت الحالي والكلي.
- **صف التحكم:** عشوائي، السابق، تشغيل/إيقاف (الزر الأكبر)، التالي، تكرار.
- **الصف السفلي:** إعجاب، كلمات الأغنية، مؤثرات الصوت، قائمة التشغيل، إضافة للقائمة، مشاركة، تحميل، سماعات.

## تخطيط شاشة مشغل الفيديو
- **ملء الشاشة:** الفيديو يظهر كاملاً.
- **الأعلى (يظهر عند الضغط ويختفي بعد ثوانٍ):** رجوع، عنوان الفيديو، إعدادات.
- **المنتصف:** زر تشغيل/إيقاف كبير يظهر لحظياً عند الضغط.
- **أسفل الشاشة:** شريط التقدم، ترجيع 10 ثوانٍ، السابق، تشغيل/إيقاف، التالي، تقديم 10 ثوانٍ.
- **الصف السفلي:** الترجمة، مسار الصوت، سرعة التشغيل، نافذة صغيرة، بث، ملء الشاشة، حفظ، مشاركة، تحميل.
- **الجانب:** رفع الصوت وكتمه.

## ملاحظات التفاعل
- على التلفاز يتم التنقل بالريموت، والأيقونة المحددة تأخذ حالة التركيز من مجموعة launcher_ui.
- الحركات مصممة لتكون هادئة ومتناسقة، ولا تشتت انتباه المستخدم أثناء المشاهدة أو الاستماع.
