# حزمة أيقونات ثلاثية الأبعاد

## المحتويات
- store/ : أيقونات تطبيق المتجر (مطعم ومقهى) - لون برتقالي
- tv/ : أيقونات تطبيق تلفاز أندرويد والقنوات - لون بنفسجي
- داخل كل مجلد:
  - static/ : أيقونات ثابتة بصيغة SVG
  - animated/ : أيقونات متحركة بصيغة SVG (حركة طفو + لمعان، وحركات خاصة لبعض الأيقونات)
  - png/ : نسخ PNG بدقة 512×512 (إن وُجدت)
- preview.html : صفحة معاينة لكل الأيقونات

## ملاحظات الاستخدام
- ملفات SVG الثابتة مناسبة للويب والتطبيقات، ويمكن استيرادها في أندرويد ستوديو عبر New > Vector Asset.
- ملفات SVG المتحركة تعمل في المتصفحات. أندرويد لا يشغّل حركات SVG مباشرة، لذلك في التطبيق استخدم نسخة PNG أو حوّل الحركة إلى AnimatedVectorDrawable أو Lottie.
- للتلفاز (Android TV) استخدم أيقونات SVG للتكبير بدون فقدان الجودة، أو PNG 512 px للحالات التي تحتاج صورة ثابتة.
- ألوان التدرج والظل مضبوطة داخل كل ملف، ويمكن تعديلها بفتح الملف في أي محرر نصوص.
